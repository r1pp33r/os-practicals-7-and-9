# Практические работы по операционным системам №7 и №9

## №7 — консольная утилита Bash

`sysinfo.sh` обрабатывает параметры через `getopt`, выводит пользователей с домашними каталогами и процессы, поддерживает перенаправление stdout и stderr.

```bash
bash sysinfo.sh --help
bash sysinfo.sh --users
bash sysinfo.sh --processes
bash sysinfo.sh --users --log users.log --errors errors.log
```

Пользователи сортируются по имени, процессы — по PID. Короткие ключи: `-u`, `-p`, `-h`, `-l PATH`, `-e PATH`.

## №9 — игра «Угадай число» по TCP

`server.c` и `client.c` используют общий заголовок `net.h`. Автоматический клиент угадывает число от 1 до 14. Сервер принимает порт, клиент — адрес IPv4 и порт. Сервер слушает `127.0.0.1` и записывает события подключений, отключений и игр в stdout.

```bash
make
./server 5014 > server.log &
server_pid=$!
./client 127.0.0.1:5014
cat server.log
kill -TERM "$server_pid"
```

Сборка без Make:

```bash
gcc -std=c11 -Wall -Wextra -Wno-misleading-indentation server.c -o server
gcc -std=c11 -Wall -Wextra client.c -o client
```

Передача целых чисел выполняется в сетевом порядке байтов. Циклы чтения и записи учитывают частичные `send` и `recv`. Обрабатываются некорректные параметры, отказ соединения и отключение клиента. Сервер обслуживает подключения последовательно.

## Требования и проверка

Linux, Bash, GNU getopt, getent, ps, GCC; для команды `make` — GNU Make. Программы проверены в Ubuntu: для №7 — справка, сортировка, перенаправление и ошибки; для №9 — две последовательные игры, журнал, неверный адрес, неверный порт и отказ подключения после остановки сервера.
